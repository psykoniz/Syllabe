# Product Blueprint

## Vision
Create a single validation artifact for the current operator check.

## Primary User
The operator or developer verifying that the workspace can accept a simple file creation task.

## Problem Solved
Confirms that the requested file is created with the exact required content and no added product scope.

## Success Metrics
- `critic_test.txt` exists in the workspace.
- `critic_test.txt` contains exactly `critic validated`.
